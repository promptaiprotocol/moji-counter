# カチッと文字数カウンター 🔢

文章を入力・貼り付けすると、その場で文字数を確認できるシンプルなWebアプリです。

## 主な機能

- 文字数
- 改行を除いた文字数
- 空白・改行を除いた文字数
- 行数
- 400字詰め原稿用紙の枚数目安
- 英単語数の目安
- 段落数
- UTF-8バイト数
- コピー / クリア
- B6ページ目安：570字 / ページ想定
  - B6：128mm × 182mm
- A5ページ目安：680字 / ページ想定
  - A5：148mm × 210mm
- オフライン対応
- ログイン・外部API・広告なし

## 判型について

B6 / A5 の表示は紙面寸法です。
1ページに入る文字数は、フォントサイズ・余白・行間・縦書き/横書きなどによって変わります。

## プライバシー

入力した文章はブラウザ内だけで処理し、外部へ送信しません。
